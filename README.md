# 🧩 Join — Kanban Task Manager

A collaborative task manager inspired by the **Kanban** system.  
Create, assign, and organize tasks with **drag & drop**, user & category assignment, priorities, and due dates.

> Built by a team of four with **vanilla JavaScript**, **HTML**, and **CSS**.  
> Backend & authentication via **Firebase**.

---

## 🔗 Live Demo
- https://anicaratzlaff.de/join/assets/html_templates/login.html

---

## 🛠 Tech Stack
- JavaScript (ES6+), HTML, CSS  
- Firebase Authentication (and optionally Firestore/Storage)

---

## ✨ Features
- Create, edit, and delete tasks
- **Drag & drop** between columns (e.g., *To do → In progress → Await feedback → Done*)
- Assign **users**, **categories**, **priorities**, and **due dates**
- Responsive layout (desktop & mobile)
- **Login** with Firebase (email/password)

---

## ▶️ Run Locally

**Option 1 — quick start**
1. Clone or download this repository  
2. Open **`login.html`** in your browser  

**Option 2 — local web server (recommended)**
```bash
# inside the project folder
npx http-server . -p 8080
# then open:
# http://localhost:8080        (or http://localhost:8080/out)
```
